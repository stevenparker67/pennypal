PennyPal PWA starter based on Version 7.1.

Upload all files in this folder to the ROOT of an HTTPS website (for example a free static hosting provider). Keep filenames together. Visit the HTTPS address on Android or iPhone and choose Add to Home Screen (on iPhone: Safari > Share > Add to Home Screen).

IMPORTANT: Your existing local HTML file and the hosted website have different browser storage. Save a PennyPal JSON backup from the old version, then use Restore backup on the hosted app. Keep the JSON file private.

This is a starter build, not a completed cross-browser security/accessibility audit. Offline caching begins after first successful online visit; do not assume browser storage is permanent.
